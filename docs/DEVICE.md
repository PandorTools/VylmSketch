# Тестовое устройство

- Планшет: POCO Pad X1.
- Проверка 25.10.2026: ADB авторизован, состояние `device`; модель системы `25099RP08G`, Android 16, API 36.
- Сейчас: палец и простой сторонний стилус. Для такого стилуса давление не предполагаем.
- Новый стилус в пути; модель и поддержку давления проверим после подключения.

## Подключение для разработки

1. В настройках планшета включить режим разработчика, затем «Отладка по USB».
2. Подключить планшет кабелем с передачей данных.
3. Разблокировать экран и подтвердить запрос на USB-отладку для этого ПК.
4. Проверить `adb devices -l`: состояние `device` означает готовность, `unauthorized` — ожидание подтверждения на планшете.

Для разработки приложения не нужны разблокировка загрузчика и отключение защиты установки приложений.
