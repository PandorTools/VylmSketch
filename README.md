# VylmSketch

Проект бесплатного приложения для рисования на планшете пальцем и стилусом.

Статус: Android-прототип 0.2.0.

Целевое устройство: POCO Pad X1. Первая платформа — Android. Предварительная техническая основа — Kotlin, Jetpack Compose для интерфейса и отдельный компонент холста с обработкой событий пера. Модель используемого стилуса пока не уточнена.

Публичный репозиторий: https://github.com/PandorTools/VylmSketch. Локальные JDK 17, Android SDK и Platform Tools находятся в игнорируемой папке `.tools`.

## Версия 0.2.0

Стартовая галерея «Мои работы» с превью и датами изменения. Создание именованного холста: альбомный, портретный, квадратный или собственный размер. Отдельное автосохранение каждой работы; возврат в галерею после успешной записи. Старый черновик автоматически переносится в работу «Мой первый рисунок», исходный файл остаётся резервной копией.

Кисть и ластик, восемь цветов, размер 1–80 px, отмена и повтор (до 12 шагов, меньше для больших холстов), экспорт PNG через системный диалог. События пера используют доступное давление; проверка с активным стилусом ещё предстоит.

Ограничения: один слой, без масштабирования жестами, настройки кисти и история отмены пока не сохраняются между открытиями работы. Размер выбирается при создании: 256–3072 px на сторону, не более 6 млн пикселей. Ластик рисует белым по белому фону. Работы хранятся только в данных приложения на планшете: перед удалением приложения экспортируйте нужные изображения.

## Сборка

Нужны JDK 17, Android SDK Platform 35 и Build Tools 35.0.0. Укажите путь SDK в `local.properties` (`sdk.dir=...`) либо через `ANDROID_HOME`.

Windows: `./scripts/build.ps1`. Другие ОС: `bash gradlew assembleDebug lintDebug`.

APK: `app/build/outputs/apk/debug/app-debug.apk`. Установка: `adb install -r app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions собирает debug APK и запускает Android Lint при push и pull request.

## Первая рабочая версия

- Холст, кисть, ластик, цвет, размер и непрозрачность.
- Рисование пальцем и стилусом; давление пера — при поддержке устройства.
- Слои: создание, порядок, видимость, непрозрачность, удаление.
- Отмена и повтор действий.
- Масштабирование и перемещение холста двумя пальцами.
- Локальное сохранение проекта и экспорт PNG.
- Крупные элементы управления и компактный интерфейс для планшета.

## Следующие этапы

Стабилизация штриха, наборы кистей, выделение и трансформация, заливка, пипетка, симметрия, импорт изображений. Поддержку отсечения ладони и наклона пера проверяем на реальном устройстве.
