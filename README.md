# VylmSketch

Проект бесплатного приложения для рисования на планшете пальцем и стилусом.

Статус: подготовка проекта. Рабочего приложения пока нет.

Целевое устройство: POCO Pad X1. Первая платформа — Android. Предварительная техническая основа — Kotlin, Jetpack Compose для интерфейса и отдельный компонент холста с обработкой событий пера. Модель используемого стилуса пока не уточнена.

Публичный репозиторий: https://github.com/PandorTools/VylmSketch. В текущем окружении не обнаружены Java, Android SDK и Android Studio в стандартном каталоге установки; сборка APK пока не настроена. Android Platform Tools установлены локально в игнорируемой папке `.tools`.

## Первая рабочая версия

- Холст, кисть, ластик, цвет, размер и непрозрачность.
- Рисование пальцем и стилусом; давление пера — при поддержке устройства.
- Слои: создание, порядок, видимость, непрозрачность, удаление.
- Отмена и повтор действий.
- Масштабирование и перемещение холста двумя пальцами.
- Локальное сохранение проекта и экспорт PNG.
- Крупные элементы управления и компактный интерфейс для планшета.

## Следующие этапы

Стабилизация штриха, наборы кистей, выделение и трансформация, заливка, пипетка, симметрия, импорт изображений. Поддержку отсечения ладони и наклона пера проверяем на реальном устройстве.

## История изменений

Локальный Git-репозиторий создан с веткой `main`, коммиты отправлены в `origin/main` на GitHub. Автор: PandorTools, адрес — GitHub noreply.

Каждую законченную задачу сохраняем отдельным коммитом с понятным описанием. Крупные изменения разрабатываем в отдельных ветках, перед объединением проверяем сборку и рисование на планшете.
